# 生命保険会社Q向け 基幹システム刷新 提案書（サマリ版）

**部署: IT / 客先: 生命保険会社Q / 作成: 2025年 / 機密度: 社外秘**

> 案件7（大規模RAG + Slack連携）の取り込み用サンプル文書です。実在の企業・案件とは関係ありません。

## 1. 案件概要

生命保険会社Q の契約管理基幹システム（稼働 22 年、COBOL）の刷新方針を策定する。段階的なモダナイゼーションにより、保守コストと新商品投入リードタイムを削減する。

## 2. 現状の課題

- 年間保守費が 38 億円で、IT 予算の 61% を占める
- 新商品の投入に平均 14 か月を要し、競合（6 か月）に大きく劣る
- COBOL 技術者の平均年齢が 54 歳で、5 年後に半減する見込み

## 3. 提案内容

- 契約管理・保険料計算・帳票の 3 領域に分割し、保険料計算から Java マイクロサービスへ順次移行
- データベースを Db2 から PostgreSQL へ移行し、ライセンス費を削減
- 既存資産の 30% は自動変換ツールで移行し、工数を圧縮

## 4. 投資と効果

- 総投資額 120 億円（5 年）、年間保守費を 38 億円から 21 億円へ削減
- 新商品投入リードタイムを 14 か月から 5 か月へ短縮
- 投資回収期間は 7 年

## 5. 体制

- PMO にコンサル 6 名、開発ベンダー 2 社、社内 IT 40 名
