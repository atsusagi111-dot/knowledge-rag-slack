# 製薬会社AJ向け 監査対応体制 強化提案書（サマリ版）

**部署: 管理 / 客先: 製薬会社AJ / 作成: 2023年 / 機密度: 社外秘**

> 案件7（大規模RAG + Slack連携）の取り込み用サンプル文書です。実在の企業・案件とは関係ありません。

## 1. 案件概要

製薬会社AJ における会計監査・当局査察・内部監査への対応が場当たり的で、担当部門の負担が大きい現状を改善する提案。

## 2. 現状の課題

- 年間の監査・査察対応が 14 回あり、対応工数が延べ 5,600 時間
- 証跡資料の提出依頼に対し、探索に平均 3 日を要する
- 同じ指摘が複数の監査で繰り返され、改善が定着していない

## 3. 提案内容

- 監査対応を統括する「監査対応事務局」を管理部内に設置（専任 3 名）
- 証跡資料を文書管理システムで一元管理し、監査項目と紐づけて即時提出
- 指摘事項を一元台帳で管理し、是正状況を四半期ごとに経営会議へ報告

## 4. 期待効果

- 監査対応工数を 5,600 時間から 3,000 時間へ削減
- 資料提出のリードタイムを 3 日から 半日へ短縮
- 繰り返し指摘を 2 年でゼロにする

## 5. スケジュール

- 事務局設置 2 か月、文書管理システム導入 6 か月
