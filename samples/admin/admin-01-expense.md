# 精密部品商社AF向け 経費精算電子化 提案書（サマリ版）

**部署: 管理 / 客先: 精密部品商社AF / 作成: 2025年 / 機密度: 社外秘**

> 案件7（大規模RAG + Slack連携）の取り込み用サンプル文書です。実在の企業・案件とは関係ありません。

## 1. 案件概要

精密部品商社AF（従業員 1,100 名）の紙ベースの経費精算を電子化し、電子帳簿保存法への対応と経理業務の効率化を同時に実現する提案。

## 2. 現状の課題

- 月 6,500 件の経費申請が紙で行われ、経理 4 名が承認・仕訳に月 320 時間を費やす
- 領収書の紛失や貼り忘れによる差し戻しが月 400 件
- 精算の入金まで平均 25 日かかり、従業員の不満が大きい

## 3. 提案内容

- スマートフォンで領収書を撮影し、AI-OCR で金額・日付を自動入力
- 承認ルートを役職と金額で自動判定し、会計システムへ自動仕訳
- 法人カードと連携し、利用明細から申請を自動生成

## 4. 期待効果

- 経理の処理工数を月 320 時間から 90 時間へ 72% 削減
- 差し戻しを月 400 件から 60 件へ削減
- 精算の入金までの日数を 25 日から 7 日へ短縮

## 5. 費用・スケジュール

- 導入費用 900 万円 + 月額 45 万円、導入期間 4 か月
