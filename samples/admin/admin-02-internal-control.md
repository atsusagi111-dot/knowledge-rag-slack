# 上場準備企業AG向け 内部統制構築 報告書（サマリ版）

**部署: 管理 / 客先: 上場準備企業AG / 作成: 2024年 / 機密度: 社外秘**

> 案件7（大規模RAG + Slack連携）の取り込み用サンプル文書です。実在の企業・案件とは関係ありません。

## 1. 案件概要

2 年後の株式上場を目指す上場準備企業AG（従業員 350 名）において、J-SOX（内部統制報告制度）に対応した統制の構築を 12 か月で支援した。

## 2. 実施内容

- 全社統制 42 項目、業務プロセス統制 6 業務、IT 統制 3 領域の整備
- 販売・購買・経理の業務フローを文書化し、統制上の要点（キーコントロール）を 118 個特定
- 内部監査室（2 名）を新設し、年間監査計画を策定

## 3. 主要な発見と対応

- 販売プロセスで与信審査の証跡が残っていなかった → 承認ワークフローを導入
- 経理担当 1 名が起票と承認を兼務 → 職務分掌を見直し、承認者を分離
- 本番システムへの変更が開発者の権限で可能だった → 変更管理手続きを整備

## 4. 成果

- 整備状況評価で不備 27 件を検出し、期末までに 25 件を是正
- 監査法人のショートレビューで「上場審査に耐えうる水準」との評価

## 5. 今後の課題

- 運用評価（実際に統制が機能しているかの確認）を上場申請期に実施
