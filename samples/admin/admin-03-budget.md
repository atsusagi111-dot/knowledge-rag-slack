# 外食チェーンAH向け 予算策定プロセス改善 提案書（サマリ版）

**部署: 管理 / 客先: 外食チェーンAH / 作成: 2025年 / 機密度: 社外秘**

> 案件7（大規模RAG + Slack連携）の取り込み用サンプル文書です。実在の企業・案件とは関係ありません。

## 1. 案件概要

外食チェーンAH（店舗 480）の年次予算策定に 4 か月を要している現状を改善し、精度の高い予算を 6 週間で策定できるプロセスを提案する。

## 2. 現状の課題

- 店舗別予算を Excel で積み上げており、本部での集計・修正に 3 回のやり直しが発生
- 予算と実績の乖離が売上で平均 12%、人件費で 15%
- 予算策定の担当者が本部・店舗合計で延べ 2,800 時間を費やす

## 3. 提案内容

- 予算管理システムを導入し、店舗の入力を Web 化して即時集計
- 売上予算は過去実績と商圏データに基づくモデルで初期値を自動算出
- 月次で予算を見直すローリング方式に変更

## 4. 期待効果

- 予算策定期間を 4 か月から 6 週間へ短縮
- 策定工数を 2,800 時間から 900 時間へ削減
- 予算と実績の乖離を売上 12% から 5% 以内へ改善

## 5. 費用・スケジュール

- システム費用 初期 2,200 万円 + 年間 600 万円、翌年度予算から適用
