# 手動確認用 36 問（文書 1 件につき 1 問）

使い方
- Slack で **本人アカウント（全部署所属）** から、ボットへの DM に 1 問ずつ貼る（DM なら `@knowledge-bot` は不要）
- 回答の「出典」に、期待ファイルが含まれていて、要点の数値が一致していれば ✅
- 「該当なし」や別文書が出たら ❌ として、質問番号を控えて報告する
